# JAVRIS — Personal Android Voice Assistant

A beginner-friendly Android voice assistant project.

## Features

- Premium black, red and blue interface
- Speech recognition using Android
- Hindi and English speech input
- Text-to-speech voice replies
- Experimental JAVRIS/JARVIS wake-word service
- GitHub Actions workflow to build a debug APK

## Build APK

1. Open the repository on GitHub.
2. Select the Actions tab.
3. Open "Build JAVRIS APK".
4. Tap "Run workflow".
5. Wait for the build to finish.
6. Open the successful workflow run.
7. Download the JAVRIS-debug-apk artifact.

## Important limitations

- The wake-word feature is experimental.
- Android may stop microphone listening in the background.
- Screen-off wake-word detection is not guaranteed.
- Voice gender depends on the voices installed on the phone.
- This starter project does not include an online AI brain.
- Microphone and notification permissions may be required.
